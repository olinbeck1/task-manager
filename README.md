# Neon Goals: офлайн-приложение

В папке `www` лежит всё приложение (index.html, иконки, манифест). Интернет ему не нужен, а данные хранятся только на телефоне.

## Вариант 1. Настоящий APK (Capacitor + Android Studio)

Нужен компьютер (Windows, macOS или Linux). Делается один раз, потом пересборка занимает минуту.

1. Установи Node.js (версия LTS) с nodejs.org.
2. Установи Android Studio с developer.android.com/studio. Вместе с ней ставятся Android SDK и JDK. При первом запуске согласись на установку SDK по умолчанию.
3. Распакуй этот архив, открой терминал в папке проекта и выполни по очереди:
   ```
   npm install
   npx cap add android
   npx cap sync android
   npx cap open android
   ```
4. В Android Studio подожди, пока закончится «Gradle sync» (внизу полоска прогресса, в первый раз это 3-10 минут).
5. Меню **Build → Build Bundle(s) / APK(s) → Build APK(s)**. Когда появится уведомление, нажми **locate**. Файл лежит в `android/app/build/outputs/apk/debug/app-debug.apk`.
6. Перенеси `app-debug.apk` на телефон (USB, облако, мессенджер). Открой файл на телефоне и разреши установку из этого источника. Приложение появится в списке как «Neon Goals».

Если захочешь поменять приложение: правь `www/index.html`, затем `npx cap sync android` и снова Build APK. Ставь новый APK поверх старого, не удаляя его, и собирай на том же компьютере: тогда данные сохранятся. Если приложение удалить, цели пропадут, поэтому периодически делай копию (см. ниже).

## Вариант 2. Установка без Android Studio (PWA)

Выложи папку `www` на любой бесплатный хостинг (GitHub Pages, Netlify Drop, Cloudflare Pages). Открой адрес в Chrome на телефоне и выбери меню «⋮» → «Установить приложение». После первой загрузки оно работает без интернета. Если нужен APK без Android Studio, загрузи тот же адрес на pwabuilder.com и скачай готовый пакет для Android.

## Резервная копия данных

В приложении справа вверху кнопка со стрелкой вниз. Она показывает все цели одним текстом: скопируй его в заметки. Чтобы восстановить цели на новом телефоне или после переустановки, вставь этот текст в нижнее поле и нажми «Восстановить».
